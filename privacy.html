HOMELAB RCLONE

Privacy Policy

Last updated: 1 November 2026

1. About this utility

Homelab Rclone is a personal utility operated by an individual for backing up data from a privately operated home server to that individual's Google Drive account. It uses the third-party, open-source rclone command-line program and the Google Drive API. It is not affiliated with or endorsed by Google.

2. Google user data accessed

When the owner authorises the utility, rclone receives permission to access Google Drive using the Google Drive API scope:

https://www.googleapis.com/auth/drive

This permission can allow rclone to list, read, create, update, and delete files in the connected Google Drive account. The configured backup process uses this access to upload backup archives, inspect the configured backup folder, and delete older backup archives when a retention rule is enabled.

3. How data is used and stored

  • Backup files are created on the owner's home server from paths selected by the owner.
  • rclone transfers the configured backup archives directly from that server to the owner's Google Drive account.
  • OAuth credentials and tokens are stored in rclone's local configuration on the owner's server. They are not intentionally sent to the website operator.
  • The website is informational only. It does not operate a server-side backup service and does not receive or store Google Drive files or OAuth tokens.

4. Sharing

Homelab Rclone does not sell or share Google user data with third parties. Google processes data under its own terms and privacy policy when the owner uses Google Drive. The owner controls the backup destination and any sharing settings in Google Drive.

5. Retention and deletion

Backup archives remain in the owner's Google Drive until the owner deletes them or a retention rule configured by the owner removes older archives. The owner can revoke the utility's Google account access at any time from their Google Account connections settings. Revoking access prevents future authorised operations but does not itself delete existing backup files.

6. Website visitors

This static website has no registration, contact form, analytics, advertising, or tracking cookies. The website is hosted by GitHub Pages; GitHub may process technical request information as described in GitHub's Privacy Statement.
