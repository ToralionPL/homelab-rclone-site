Homelab Rclone

A small, privately operated utility for backing up a home server to the owner's Google Drive.

Homelab Rclone uses the open-source rclone command-line program and the Google Drive API to transfer backup archives from a privately operated home server to a Google Drive account controlled by the same owner.

What it does

  • Runs on the owner's own home server; this website does not run the backup software.
  • Uses Google Drive access authorised by the account owner.
  • Uploads locally created backup archives to a folder selected by the owner.
  • May list or delete older backup archives in that folder when the owner has configured a retention rule.

Data and privacy

Backup contents and OAuth credentials are handled by rclone on the owner's own server. This website does not receive backup files, Google Drive contents, OAuth tokens, or Google account credentials. The utility does not provide a hosted account, analytics, contact form, or user-tracking feature.

Google Drive data is accessed only to perform the backup and retention operations initiated by the owner. The website operator does not independently collect, sell, or share Google user data.

For details, read the Privacy Policy.
